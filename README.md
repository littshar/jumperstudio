# Jumper Studio

把一段人的舞蹈视频重定向到开源螃蟹机器人 [Jumper](https://github.com/KingKongRobotics/jumper)（22 自由度六足螃蟹）上。

- **左栏**：导入视频 + Sports2D 检测叠加（人物识别框、骨架，两个独立开关）
- **右栏**：MuJoCo 渲染的 Jumper 螃蟹跟着跳舞（运动学木偶，不会摔倒；鼠标拖动旋转视角、滚轮缩放）；可选"幽灵手臂"——从人体通道重建的双臂 3D 参考骨架悬浮在螃蟹上方，与钳子动作同屏对照
- **曲线区**：上图为躯干欧拉角（pitch / roll / yaw），下图为重映射后的钳关节指令 J0–J4（实线 LF 左钳 / 虚线 RF 右钳；同色点线 = 关节限位，曲线贴线即饱和）
- **进度条**：点击或拖动跳转（点击直接落到鼠标位置），拖动时视频 / 螃蟹 / 曲线游标三向同步；点击曲线图任意位置也能跳转
- **历史**：`🕘 历史` 按钮列出最近分析过的 8 个视频（缓存命中秒开）；启动时自动加载上一次的舞蹈
- **设置**（进度条左侧 ⚙ 按钮，即时生效并记忆）：显示/隐藏曲线区、重定向映射标注（预览窗口右上角，含实时数值）、幽灵手臂、视频识别框/骨架叠加、转身段默认开关、**螃蟹站高调节条（70%–155%）**、**单人跟随 / 多人模式（每人一只螃蟹，按站位排开）**、切换螃蟹背景（默认 / 深海 / 落日 / 沙滩 / 霓虹）

## 重定向规则

| 人的动作 | 螃蟹的响应 |
| --- | --- |
| 躯干倾角（pitch/roll，yaw 为 2D 近似） | 身体姿态角（缩放增益 + 限幅；yaw=0 时正面朝向预览相机） |
| 腿长比例（腿长/躯干长，尺度无关） | 站立基准高度 |
| 下蹲程度（髋-踝距离/腿长） | 身体高度起伏（四条腿解析 IK，转身时足端原地枢转）；**腿出画/半身特写时自动回退正常站高**，不会掉到最低 |
| 手臂两段的方向（大臂 = 肩→肘，钳子指向 = 小臂） | 钳 J0–J3（方向跟踪 IK：大臂方位 + 肘弯角为硬目标，手掌位置为软目标） |
| 手举过肩 | 钳爪张开（J4，暂不参与映射，保持静止值） |
| 跳跃（髋与双脚同时高于站立基线） | 螃蟹原地跳（下蹲发力 → 腾空 → 落地，高度约 0.75× 站高） |
| 抬腿（单侧脚踝抬高） | 同侧行走腿抬离地面（后侧腿跟随 40%） |

钳部映射是**方向跟踪 IK**，再用用户给的锚点关系做一次常量校准：幽灵手臂在滑条 (前后, 侧摆, 肘弯) = (90°, 90°, 180°) 时，左钳 J0–J4 应处在关节扫动里的 −60°, 0°, 30°, 20°, 2°（相对静止姿势），右钳镜像。这只校准一个固定偏置，不改变映射本身——别处的钳子仍然跟着幽灵手臂的方向走。

所有钳部关节方向（抬升/合拢/外展/张开的正负号）和腿部关节轴向在加载模型时**实测标定**，不依赖硬编码镜像表。钳肩 J0 有可用限位：左钳最高 +30°、右钳最低 −30°（`CLAW_J0_LIMIT_DEG`），避免开局时左臂插进前腿；两个钳的小臂 J1 在预览和训练里都不低于 **−110°**（`CLAW_J1_MIN_DEG`）。

**转身段**：|yaw| 持续超过阈值判定为"疑似转身"（2D 方向镜像模糊处），在进度条上方的时间轴上标为药丸块，**每按一次在三态间循环：空心 = 关（跟随 yaw 曲线）→ 实心 = 整圈 360° → 半填充 = 半圈 180°「背对相机」**（无转身段时不显示）。半圈适合"人其实只是转过去背对镜头"的场合，整圈适合真正的旋转。设置 → 重定向 → 「转身段默认整圈旋转」控制新视频的初始状态（默认开）。脚本旋转叠加在实时 yaw 曲线上（起止连续、出段不回抽），角速度限幅 450°/s——检测段太短时转到段外几帧补完，不会甩；切换任一药丸都会即时重算其后所有旋转段，无需重新识别。

**多人视频**：检测到多个人时（最多 6 只螃蟹），设置 → 重定向里可切换单人跟随（自动=最完整的人，或指定人物 N，下拉里显示每人的有效帧百分比），或开启**多人模式**——每人一只螃蟹，按画面中的站位左右排开（视频里靠左的人，螃蟹也站舞台左侧，未跟随的人识别框显示为灰色）。多螃蟹可以直接用鼠标拖动微调站位，头顶编号对应视频面板里的人物编号。**轨迹自动修复**：群舞里遮挡会让追踪器把同一个人拆成好几段"人物"——识别改为保存所有可用轨迹（不再让"最大体积"排序挑中毛刺轨迹），载入时再自动缝合断续轨迹、合并重复检测、剔除无效轨迹（状态栏会报告），对已缓存的视频同样生效。实测新宝岛含运镜片头的 35 秒片段：识别出 7 人、前 6 人有效帧 53%–84%（旧版只有 8%–22% 的碎片）；**不需要手动裁掉开头的运镜段**。旧缓存用 `↻ 重新识别` 重跑即可享受完整修复（1080p 全片约 7–10 分钟）。

**自定义背景与地面**：设置 → 螃蟹背景 → 「背景图」「地面贴图」「清除」可用自己的图片（地面会成为真实透视贴图，需要重建 3D 模型，约 1 秒）。「钳关节校准」对话框有两种模式，手动幽灵里带关键帧校准：**关节扫动**十根滑条逐关节摆钳子（左钳 LF / 右钳 RF 分开，度数 = 相对静止姿势的偏移，滑条范围就是关节真实限位——发现限位或方向不对一眼可辨）；**手动幽灵**六根滑条摆幽灵手臂（左右臂各三根：肩前后 −90°向后↔180°过头、肩侧摆 −120°↔0°（0 为竖直，负值向外，两臂镜像）、肘弯曲 180°伸直→0°折起），螃蟹钳按视频重定向的同一套 IK 实时跟随，并按锚点校准（幽灵 90/90/180 → 左钳读数 −60/0/30/20）；读数用关节扫动的同一约定。**手动幽灵**同时显示幽灵臂和十根钳关节滑条：摆好幽灵臂后自由调钳关节，点「记录关键帧」；相邻两帧的关节角度比就是映射比例（例如 J0 从 0° 到 20°、幽灵对应角从 0° 到 25° 就是 80%）。每个关键帧都把「手动钳角度 − 当前映射角度」作为偏置，按控制角插值后加到原有向量映射上；一个点即全局偏置，多个点分段，并立即重建当前视频。校准保存在 `~/.crab_dance_cache/claw_calib.json`，「清除校准」可删除。J0 采用用户给定限位 LF −70°~+15°、RF −15°~+70°；先做 0.2 秒 J0 低通，再加逐帧网格接触补偿，实测这段舞蹈 1789 帧无左右钳互穿、前 5 秒无抽搐。静止姿势已按模型实测校准：J0 无偏置（HOME 即左右镜像对称）、J1 −30°（钳臂平面与地面平行）。

**动作模仿训练页**：主界面右上角「进入训练 →」把当前识别结果（参考关节轨迹 + 跳跃段）带进整页替换的二级训练页：「实时画面」开关、**两个独立的渲染窗**（「训练渲染 · 物理仿真」显示真实的 MuJoCo 动力学 + 地面摩擦 + 钳自碰撞接触；「策略预览」训练时实时显示第二个并行环境的当前策略，训练/停止后回放完整舞蹈，可拖动旋转、滚轮缩放、暂停/播放）、大进度条、**实时训练日志**（每轮 return / track / stab / hands / smooth / survive / 终止率 / 存活率 / 用时，以及参考轨道和权重文件路径；自动吸附到最新一行，不用手动拖）、右侧的**日志/原视频共用窗口**（训练时显示日志，训练结束开始察看结果时自动切换成**原视频**并与物理回放同步，点「训练日志 / 原视频」两个标签可随时切回）、归一化回报与各奖励分量曲线，训练完成后才可点的「导出权重」；底部有「回放」按钮。底部「参数」打开**训练参数**窗口：窗口顶部先选**训练方法**（PPO / SuperMimic 禁用 / Smoke），下面分为 **PPO 训练配置**（num_envs、自动计算的 PPO 采样批量 = num_envs×24（分 4 个 mini-batch 更新，Jumper 没有独立 batch_size）、iterations，默认 **2048 / 300**（从固定预训练权重微调；实测 2048 envs ≈ 1.6 秒/轮，300 轮 ≈ 8–9 分钟））和 **Smoke 参数**（训练动作精度、训练数量、训练轮数、双手安全距离、高度/倾角终止阈值、物理子步）；同时显示本机总/已用/可用内存、Smoke 预估占用与剩余内存、**预估时间**、显卡信息、**真实的 Jumper 训练环境**（检查 `D:\jumper_ws` 与 warp:cuda，和应用自身是否装了 torch 无关），GPU 每轮耗时优先用**上一次训练实测值**（缓存在 `~/.crab_dance_cache/jumper/speed.json`），没有实测时才按无窗口短测粗估；并按实测物理速度给出Smoke 的**推荐数量 / 推荐轮数**（约 75 秒预算），可一键应用；预估只在打开窗口时或点击「计算预估」时刷新。训练在真实 MuJoCo 动力学里做 PD 全身跟踪（重力、摩擦、接触、钳自碰撞），奖励 = 跟踪 + 高度/倾角稳定 + 双手距离/自碰撞惩罚 + 平滑 + 存活 + **身体 yaw 跟踪（更大权重）** + **后腿离地惩罚（LR/RR 不落地就扣分）** + **跳完落地姿态奖励（越直、越贴参考高度、后腿越稳，奖励越高）**，终止条件在训练中保持激活；上半身残差动作按手部接近程度门控。站姿：**两条前行走腿 LM/RM 全程向前伸 30°**（`FRONT_LEG_J0_STANCE_DEG`，主预览和训练都生效；LM_J0 的预览范围为此做了沙盒放宽）、训练参考再叠加身体抬头 10° 和 **两臂钳 J0 前摆 50°**（夹在无碰撞窗口内），避免钳子蹭地、开局左臂不再插进前腿；训练渲染和策略预览都可以**鼠标拖动旋转 / 滚轮缩放**，策略预览可暂停。Smoke 开始时写参考 NPZ（times/qpos/joint_names/jump_mask/jump_segments/fps/supermimic_config），训练完用最优策略在物理仿真里跑完整段舞蹈并记录每个仿真状态（播放帧率与原片一致、不会慢放），权重 NPZ 里同时带 dance_times/dance_qpos。注意：Smoke 是 CPU 版 MuJoCo 物理 + ES；PPO 后端在 `D:\jumper_ws\.venv` 里跑 Jumper/mjlab（torch cu126 + warp:cuda，连 MuJoCo 物理也在 GPU），应用自身的 Python 有没有 torch 都不影响训练，参数窗口也不再拿应用自己的 torch 判断显卡。

**PPO 训练（参考跟踪，Windows 原生）**：训练页底部有「训练方法」选择，默认 **PPO**（检测到 `D:\jumper_ws` 时可用；`CRAB_JUMPER_WS` 环境变量可改路径），另一个是 **Smoke · CPU 物理 + ES**。PPO 后端把当前舞蹈交给 Jumper 官方的 mjlab/rsl_rl 全身跟踪栈训练，点「开始」即可：

> **这不是 SuperMimic。** 这里的 GPU 训练是 Jumper 官方 mjlab 的 **rsl_rl PPO 参考跟踪**；真正的 SuperMimic（世界模型 + 32 步想象 rollout，见 `Shimingyi/allmimic`）目前只支持 **Unitree G1 / 29 DoF**。22-DoF 螃蟹的机器人配置、任务/世界模型维度、动作库格式、关节权重都还没有移植，所以「调整参数 → 训练方法」里的 SuperMimic 选项是**禁用**的，并会显示缺少什么。不要把 PPO 当成 SuperMimic。

1. **导出片段**：`app/core/jumper_clip.py` 把识别结果写成 Jumper `jumper.dance` 格式（`meas_*` 通道）：支撑腿用 3-DoF 数值 IK 重新落脚（J0 参与，身体俯仰 20° 时仍保持四脚共面），底座高度平移到 Jumper 标定的 `STAND_Z`，跳跃只抬底座不抬腿 IK，最后按 26 rad/s 做斜率限制（低于伺服 30.7 rad/s 拐点速度）；因此能通过 Jumper 的连续性 / 关节限位 / 四脚共面三项检查。
2. **生成任务**：写入 `D:\jumper_ws\tasks\jumper\dance_crab\`（`media/crab.npz` + 自动生成的 `env_cfg.py`/`rl_cfg.py`/`__init__.py`，奖励尺度按片段的实测关节位置/速度 RMS 与竖直范围计算），并确保 `tasks/__init__.py` 注册该任务。
**固定预训练权重**：`assets/pretrained/dance_base.pt` 是从 `logs/jumper/jumper.dance_crab/2026-11-18_13-44-07/model_999.pt` 复制的第 999 轮检查点（离线 2048 envs × 1000 轮训练，约 30 分钟），随应用打包。界面不再从零训练，每次都以它为初始参数微调当前舞蹈，默认 2048 envs × 300 轮（约 8–9 分钟）。最终训练指标：平均回报 **46.5**、存活 **500/500**、关节位置 L2 误差 **0.83 rad**、身体位置误差 **0.025 m**，录制的完整 60 s 回放里螃蟹全程站立、动作随参考变化。对比原 512 envs / 30,000 轮（约 8–10 小时、4400 轮时关节误差 1.5 / 身体 0.035 / 存活 283），用更高的并行环境数 + 已有权重热启动，把基础训练压到半小时且指标更好。注意：把高站姿转身/跳跃技能权重直接热启动到舞蹈 **会把策略带到“站得稳”的局部最优**（关节误差约 2.5、回放基本站着），所以 PPO 舞蹈的基础初始化应使用舞蹈检查点，而不是技能权重；技能权重留给后续的课程/辅助损失实验。检查点：`logs/jumper/jumper.dance_crab/2026-11-18_13-44-07/model_999.pt`。要升级基础权重，把新的 `model_XXXX.pt` 覆盖为 `assets/pretrained/dance_base.pt`，并把 `assets/pretrained/dance_base.json` 的 `iteration` 改成对应轮次；应用下次训练会自动使用。

3. **训练**：以子进程运行 `app/core/jumper_live_train.py`（它加载 Jumper 的 `scripts/train.py`，命令行参数完全相同），从 `--task jumper.dance_crab --backend warp --device cuda:0 --num_envs 2048 --max-iterations 300 --checkpoint "<应用目录>/assets/pretrained/dance_base.pt"`（默认微调；可调）一路走官方训练流程。**不会打开任何独立窗口**：包装脚本把 1 个环境离屏渲染成 JPEG（5 fps），应用把它显示在左侧「训练渲染」窗内，关掉渲染开关即完全不取画面、训练更快；日志、每轮平均回报、关节/身体跟踪误差、存活时长实时进入页面的日志和曲线。实测本机 512 envs 无渲染 ≈ 1 秒/轮；2048 envs ≈ 1.6 秒/轮（约 30k steps/s），300 轮约 8–9 分钟。Jumper/mjlab 的奖励**不是 0–1**：8 个正向跟踪项权重合计 6.5/步，奖励管理器再乘 `dt=0.02 s`，500 步回合的原始上限 ≈ 65；训练页顶部曲线因此按理论上限归一化显示（「累计回报/满分」和「单步回报/上限」两条，0–1），日志里仍打印原始值。训练时长取决于轮数和机器负载；默认 2048 envs / 300 轮是从固定预训练权重微调的配置（约 8–9 分钟），参数窗口的推荐也是 300 轮。这是**真正的 rsl_rl PPO**：每轮用 num_envs 个环境各走 24 个控制步采样，再分成 4 个 mini-batch 更新，没有单独的 batch_size 参数。可随时「停止」；训练始终从固定预训练权重开始，每次微调都新建一个训练目录，历史记录可在「训练历史」里查看/删除。
4. **策略回放**：训练结束后自动用 `scripts/play.py --headless --steps <舞蹈帧数> --video … --states-out …` 把最优策略在物理仿真里跳完整段舞蹈。应用优先加载 `--states-out` 写出的逐帧 root/joint 状态，在「策略预览」里用应用自己的 MuJoCo 播放，可**鼠标拖动旋转、滚轮缩放、暂停/播放**；停止训练后自动录完整段，不再只显示前几秒。
5. **导出**：「导出权重」保存最新的 `model_N.pt`（同一运行目录里还有 mjlab 导出的 `.onnx`）。

环境准备（一次性）：`D:\jumper_ws` 是 Jumper 仓库，`.venv` 内装好它的依赖（mjlab/mujoco-warp/warp-lang/torch cu126）；训练子进程会设置 `TORCHDYNAMO_DISABLE=1`（Windows 上没有 Triton）。若目录不存在，GPU 后端在界面里自动禁用并显示原因。

**3D 渲染异常**：连续失败时螃蟹预览会显示「3D 渲染不可用」，带**重试 / 查看诊断**按钮（重试会重建所有渲染器，诊断显示最后一次异常的完整 traceback）；重试面板跟随预览区尺寸，窗口布局不会因为清空画面而跳动。

**实时播放**：播放按墙钟推进，多螃蟹渲染慢时自动丢帧保持原速，不会慢放。

> 唯一需要手动安装的是 Python 解释器。所有 Python 包（包括 MuJoCo）都会装进项目目录下的 `.venv`，不会污染系统环境；系统里装过 mujoco 也不会被使用。

### 首次安装步骤

1. 安装 Python 3.11（python.org 安装包，勾选 Add python.exe to PATH）。
2. 下载 / 解压本项目（或 `git clone`）。
3. 双击 `setup_windows.bat`，等待脚本完成：创建 `.venv`、安装依赖、下载机器人模型、可选配置 `D:\jumper_ws` 训练环境、创建桌面快捷方式。
4. 之后双击桌面快捷方式 **Jumper Studio**，或运行 `start_windows.bat` 启动。

只做预览 / 视频识别、不需要 GPU 训练时，可运行 `setup_windows.ps1 -SkipJumper`，跳过训练环境。

## 安装

**环境诊断 / 安装 / 卸载**：第一次进入训练页会自动诊断应用虚拟环境、机器人模型、预训练权重、Jumper 训练仓库与虚拟环境、CUDA torch、mjrl/mjlab、回放补丁和桌面快捷方式；缺失时会询问是否自动安装或修复。之后可在「设置 → 环境诊断」再次检查。对话框里可单独勾选组件执行「安装 / 修复」「重装」「卸载」，并实时显示安装日志。训练环境的虚拟环境与缓存也可以在命令行单独卸载：`uninstall_windows.bat`（应用自身环境需先关闭应用）。

**一键配置（推荐）**：双击 `setup_windows.bat`（或运行 `setup_windows.ps1`）。它会同时配好本软件环境和 SuperMimic/Jumper GPU 训练环境（`D:\jumper_ws`），可换路径/跳过 torch/GitHub 镜像，训练进行中会拒绝改动环境。环境清单、版本表、手工步骤和训练耗时见 **[SETUP_WINDOWS.md](SETUP_WINDOWS.md)**。

手工安装本软件：

```bat
cd crab-dance
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python run.py --fetch
.venv\Scripts\python run.py
```

- `--fetch`：从 GitHub 下载 Jumper 模型（jumper.xml + 76 个 STL，保持官方目录结构）。若直连失败，设置镜像前缀再跑：
  `set JUMPER_MIRROR=https://ghproxy.net/https://raw.githubusercontent.com`
- 首次分析视频时 Sports2D 会自动下载 RTMPose ONNX 模型（约几十 MB，需联网；之后离线可用）。
- 分析结果按视频内容哈希缓存在 `~/.crab_dance_cache/`，重复导入秒开。

## 命令行

```bat
.venv\Scripts\python run.py --selftest          % 模型标定 + IK + 重定向数学自检
.venv\Scripts\python run.py --video dance.mp4   % 启动并自动载入视频
.venv\Scripts\python -m tests.test_retarget     % 离线单元测试（无需 GUI）
```

## 已知近似（单目 2D 的固有局限）

- **yaw（转体角）**来自肩宽透视缩短，是弱估计，因此映射到螃蟹时增益和限幅都收到较小值。
- 舞者背对/面对镜头会导致 pitch / roll / yaw 方向相反：改 `app/constants.py` 里的 `BODY_SIGN_ROLL / BODY_SIGN_PITCH / BODY_SIGN_YAW`（±1）逐通道翻转。
- 手部"张开"以手腕高于肩部近似（2D 无法测手指张开度）。
